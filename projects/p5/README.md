# P5 跨领域编程交付

- 基础小游戏用浏览器碰撞模型和 Python 判题复现边界接触、包容和负坐标。`MotionKernel.cs` 提供独立 .NET 时间推进练习，分别用 35 ms 和 15 ms 验证总模拟时间 40 ms，再将纯逻辑接入 Unity。Unity 编辑器和真实引擎物理需在本地工具测试。
- 中阶控制项目比较两个 PID 参数，只改一个增益，记录误差。差速车轨迹与独立折叠频率协助验证采样和执行器约束。`g++ -std=c++17 -Wall -Wextra -Werror projects/p5/embedded.cpp -o /tmp/nico-embedded` 编译固定容量队列，再运行 `/tmp/nico-embedded`，复核满队、回绕、空队和真实输入 0。此队列用于单一拥有者，硬件同步需板级验证。
- 进阶项目在浏览器核验有冲突与无冲突的定位，再调节阈值、测量噪声和地图障碍。提交观测矩阵、至少一条由路径前驱重建的实际路线、残差与资源约束。输入是教学场景，报告注明一维位姿图、理想平面运动与真实设备的距离。

工作样本使用合成数据。项目报告区分已运行结果与外部工具验证，不生成或覆盖原有美术资源。
