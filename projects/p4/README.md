# P4 项目参考实现

在仓库根目录执行 `python projects/p4/verify.py --output project-evidence.json`。Python 3.10 及以上自带的标准库足以运行。可以用 `--only numerical` 等参数单独运行，也可以换 `--seed`。HTTP 流程使用虚构数据和随机分配的本机端口。全部临时进程由验证脚本关闭。

| 任务 | 交付物和任务流程 | 独立核验 |
| --- | --- | --- |
| `numerical` | 实现 `solve`、`simpson`、`rk4`。交付误差随步长变化的表格和一个失败案例。 | 由已知向量制造右端项、立方函数原函数、指数方程闭式解、近奇异限制 |
| `language` | 扩充整数语言，为绑定、条件和重复语句写语法，提交 AST 与执行输出。整数除法向下取整，`let` 在同一全局作用域支持重绑定。 | 原生整数表达式作为比较，对结合律、括号、未绑定、除零和语法错误测试 |
| `distributed` | 将平方和拆成四个进程；人为断开一个返回，重建工作进程并让每片只提交一次。 | 跟单进程 `fsum` 对照，记录新 PID、故障和重试，覆盖空数据 |
| `pipeline` | 读 JSONL，经校验、去重及水位线进入 SQLite。交付初次运行、重放及后续批次的血缘。 | 独立写出三个窗口应有的计数与和，校验迟到、无效数据、冲突和配置变更 |
| `ai` | 训练二元模型、保存并重载 JSON 权重，在本机 HTTP 端口预测。交付冻结版本与留出点的误差说明。 | 对照人工标注的四个独立点，拒绝过期版本及错误维度 |
| `service` | 提交持久业务键、并发工作负载、SLO 与恢复实验。重开来自 SQLite 备份的新实例，检查同键不重写。 | 72 次请求分别核对 24 笔创建、48 笔重放，另检验冲突、非法输入和恢复后数据 |
| `paper` | 完整实现 Dijkstra 1959 文中的两个算法。用带权图分别验证最小生成树和最短路，并单独核查论文中的有向推广。 | 枚举树验证最小权重，Floyd–Warshall 独立比较每对路径；核查起终点、路径代价和候选状态不变量 |

每项手工量规用 100 分。算法或服务结果占 40，复现材料和可运行说明占 25，边界与失败处理占 20，结果解释及局限占 15。验证脚本只核验表中列出的可执行结果。提交时一并附上修改的源码、运行报告，说明假设与一个局限。

系统、数据和模型服务证明的是本机端到端执行。多机选举与安全恢复、真实业务负载、远端部署和依赖集群需另外验收。论文研究是原文中两项算法的完整电脑复现，用现代合成图和独立参照。原文不含可下载数据集或性能基准。这里不复述作者当年的计时或硬件推断。[Dijkstra · A note on two problems in connexion with graphs](https://ir.cwi.nl/pub/9256/9256D.pdf)
