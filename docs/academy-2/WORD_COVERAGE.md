# Nico Academy 2.0 Word 蓝图对照

本轮落实《Nico Academy 2.0 完整课程规划》的课程体系、页面和入口。Word 对旧仓库的数量是历史快照。实施基线 `f71c014` 的真实数据为 212 个条目、116 节可学课。

| Word 章节 | 本轮对应结果 |
| --- | --- |
| 一 · 课程问题 | 数学、统计、算法和数据科学独立。办公与工程应用和数据科学分属不同领域。修正混用 M02 线性代数与 M05 离散数学的先修关系。 |
| 二 · 平台定位 | 首页以计算机科学、数据科学与 AI 为主线，十领域并列，专项应用保留游戏、硬件与办公自动化。 |
| 三 · 三级结构 | `#/courses` 以三个阶段组织 30 个入口，可搜索名称、主题和旧编号；每个入口都有模块、章节、知识点和实践目标。 |
| 四 · Foundation | 十门基础大纲从数学、统计、算法和数据素养开始。匹配内容显示可学课时，用原播放器打开。 |
| 五 · Intermediate | 十门中阶大纲涵盖大学核心主题。A、B 与 C 已完成的中阶课分流至对应领域并保留原 ID。 |
| 六 · Advanced | 十门进阶大纲和实践目标可浏览，科研和各专项作为按需扩展。新增教学仍列为规划。 |
| 七 · 合并旧课 | 每个旧编号有唯一主归属。数据库共用数据科学入口，算法、编译器、办公自动化按蓝图迁移。关联项复用原地址，跨领域展示不会重复统计。 |
| 八 · 知识关联 | `#/graph` 支持查看先修和后续课程；模块、知识点与旧课时有复习链接。Attention 提供可跳转的五项先修。勾选自评不写学习成绩。 |
| 九 · 实验功能 | `#/lab` 有 7 个实验空间。Math Lab、Statistics Lab、Algorithm Arena 和 Systems Lab 有可操作内容，三个其他入口接上可用课时或资源，并列出计划功能。 |
| 十 · 个人学习路线 | `#/paths` 有六条专业主线、本机固定和首页推荐，提供 Word 中数据科学与 AI 的学习时间和分期建议。未完成的原续学位置优先。 |
| 十一 · 教学标准 | `#/resources` 列出十二项模块教学标准及从零实现和专业库的教学方法。既有课按原内容和质量状态显示。 |
| 十二 · 公开教材 | 13 个 Word 教材/课程来源，另列 CS2023 与 MIT 6‑4 两个参考框架。 |
| 十三 · 开发顺序 | 资源页列出 P0–P5，区分已接入架构、初始实验和后续建设。 |
| 十四 · 设计原则 | 首页用少量大入口组织内容；模块内显示细分知识、迁入课时、练习入口、项目和相关先修。 |

## 兼容与内容边界

- 原课时地址、艺术资源、测验与模拟器、AI、进度和徽章继续沿用。专业主线选择独立保存在本机。浏览课程大纲和自评先修不写课时进度。
- 老版检索和分阶段列表可从 `#/courses?view=legacy` 与 `#/paths?view=legacy` 打开。原 `#/paths/a`、`#/lesson/...`、`#/lab/prompt` 和 `#/lab/tutor` 仍可直接访问。
- Word 中的知识点与项目作为大纲接入。正式教学、模块综合评估、完整训练工作台和研究记录按后续阶段开发。
