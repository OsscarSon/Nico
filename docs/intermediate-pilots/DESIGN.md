# 中阶首批课程设计

1. 使用目录已预定的 B-I01、C-I04、C-I05。中阶课以原目录编号作为稳定的课时 ID，复用播放器和进度格式；基础阶段及未开放节点沿用原行为。
2. B-I01 在现有 Python Worker 中处理本地临时 CSV，验证表头换序、对象状态、缺文件与非法时长，同时解释标准库、模块、类型与测试。
3. C-I04 用虚构图书馆资料验证权限、JSON 和对照评测；C-I05 对两版资料实际分块、向量检索、重排及核对证据。两门均为本地教学模型。
4. 各课附独立插图、自由实验、实际判分、三道诊断题、迁移和权威资料，保留草稿；用 1440、390、360px 完整验证。
