## 核验口径

目录仍有十领域、30 个主要课程入口。算法三个阶段覆盖 12、26、22 项，共 60 个课时。三阶段共用 48 个真实执行模型。有 22 个课时带 Python 编程题，其余知识点通过 TypeScript 实验、分层答题和迁移核验练习。

蓝图的 12 项标准由同一课时播放器承载。编程与标准库对照安排在有明确函数规格和可判定输出的课时。停机、可计算性及复杂度理论主要采用有限模拟、证明或证书核验。项目设计另见 [实施及验收](IMPLEMENTATION.md)。
