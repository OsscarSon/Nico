## 本轮发现并修正的问题

| 领域 | 缺陷及修复 | 独立证据与边界 |
| --- | --- | --- |
| 二项尾概率及实验功效 | 从 `P(X=0)` 开始递推在样本较大时下溢。改从众数累积相对质量并归一化，利用右尾单调性求最小拒绝阈值。 | 公平硬币 `n=1999` 时 `P(X≥1000)=0.5`。100 个边界及中心场景对照 SciPy，最大绝对误差 8.33 × 10⁻¹⁵。离散检验的实际显著性可能低于名义值。 |
| 标量 Kalman 滤波 | 高预测方差下增益可舍入成 1，直接乘 `1−K` 使后验方差错误归零。改用由后验精度导出的有界形式。 | `P=10²⁰, R=1` 的后验方差约为 1。`P=R=10³⁰⁸` 为 5 × 10³⁰⁷。教学推导限定独立标量测量。 |
| PCA 与模型指标 | 固定次数幂迭代在近重根时会选偏主方向。改用小型对称矩阵的 Jacobi 正交旋转，拒绝无穷或 NaN 的阈值及回归标签。 | 解析近重根算例与 120 个 NumPy 参照矩阵。用协方差元素尺度归一化后，最大特征方程残差为 1.58 × 10⁻¹⁵。AUC 平局计半分，单类 AUC 和恒定目标 R² 无定义。 |
| 精确随机化检验 | 固定绝对误差阈值会把不同统计量判相等，导致换计量单位时改变 p 值。比较前统一中心和量纲，并保留原量纲的观测差。 | [1,2,9,10] 的 2 对 2 双侧穷举有 6 种分派、2 种至少同样极端。缩放至 10⁻¹² 后仍为 1/3。36 个场景与 Python 精确分数枚举一致。 |
| 编译求值顺序 | 常量折叠阶段可能提前抛出溢出，盖过原解释器中较早出现的未绑定变量错误。将会溢出的子式留给运行期，变量绑定也检查安全整数。 | 对照同一解析树的解释器和字节码执行器，覆盖未绑定、溢出、运算优先级及减法左结合。 |
| P5 项目证据 | 过去仅证明两次运行不同，可能用两个不相干输入得分。补齐正重叠与真正贴边、只变积分增益及一致与不一致 SLAM 观测的条件。 | 核对正重叠面积、共享边线、完全分离、拟合残差及反例。保留正常提交和原有进度格式。 |
| 八份旧课 | 补主要来源，修正 sRGB 中间码值与亮度、Unicode 码位与文字显示单元、IPv4 /31 与 /32、DNS 冷缓存路径及否定结果。 | 重新穷举课内布尔门和加法器，复跑编码与掩码答案，并对照标准适用范围。历史快照仍逐项比较，八份有意修订的旧课固定了对应的新哈希。美术哈希检查照常。 |
| 统一备份 | 导入失败后，成功回滚仍残留一个可能很大的恢复副本。回滚成功后清理该副本，无法回滚时保留手工恢复入口。 | 存储配额、部分写入、回滚及后续导入回归。现有备份版本与数据键保留。 |
| AI Tutor | 讲解推导时上下文缺少明确的步骤公式和正文。将这些公开教学内容限于推导模式，答题提示只选取公开步骤标题。 | 输入输出边界单测及启停回归，未调用真实第三方服务。 |

- 全 604 项已对应正式课时或原版互动课、原有稳定 ID 和可追溯的引用字段。250 条独立公式及分步公式通过解析检查。解析检查仅验证排版输入，台账另外记录 58 项带具体算例、标准对照或工具链执行证据的知识点。

- 实际工具链以隔离的小例子为界。Unity 编辑器和场景、物理 Arduino 板与传感器、CUDA 硬件、多主机集群、生产云服务、真实 AI 服务及辅助技术设备未验证。
