表按知识点统计。若同一旧课被多个知识点引用，编程覆盖含不同的映射。结构化题统计包含多选、矩阵、字段、配对、排序和步骤题。题目数为默认题集到达的数量，种子变式和旧题另计。所有计数按当前代码生成，逐行链接和题数见[台账](LEDGER.md)。

本轮新增 42 道固定结构化题、4 个带独立算例的种子题族、7 个编程任务、12 组推导或证明。种子分支接入现有题库及掌握度机制，口头阅读或自评仍不产生正式掌握成绩。

| 教学领域 | 典型新增任务 | 错误诊断 |
| --- | --- | --- |
| 数值与优化 | 截断与舍入分账、周期热传导、Newton 更新、约束优化、整数规划、复数 DFT | 从中间结果定位符号、边界、实虚部方向和舍入错误 |
| 高阶统计与研究 | 指定顺序似然与汇总似然、MAP 端点、穷举 Bootstrap、非对称提议、Kalman 精度、检验功效 | 分别核对数学对象、实际显著性、模型条件和有限样本分母 |
| 编译与分布式 | 解析树、常量折叠异常、Lamport 时钟、CAP、两阶段提交 | 用输入失败和分区场景检验控制流及顺序 |
| 数据工程 | 集合投影与多重集、快照隔离、日志恢复、Parquet 裁剪、Kafka 分区 | 让学习者判断正确假设，避免机械记忆术语 |
| AI 与研究方法 | 非对称卷积核、Transformer 掩码、扩散重建、LoRA 更新、终止态 Q 学习、消融与隐私预算 | 匹配因果范围、检查矩阵形状、核算终止态和假设条件 |
| 编程任务 | RK4、二项尾、Markov 链、后验预测、分类多数阈值、互相关窗口、基于时间的窗口汇总 | 双实现结果在 CPython 核对，共 112 次，包含固定值和种子样本；浏览器还用 Pyodide 跑过学员实现 |

期望值对照优先采用外部数值库、精确分数或不同表达式。矩阵及多步骤题覆盖了真实错误及解释。课程范围内已有正式判分器；本次未为所有 42 道新题建立各自独立的自动化答案夹具，仍需人工复读和扩展验证。P4 还有 191 个课时没有此表所列的结构化题，196 个没有对应编程题。旧版练习保留，原有进度、课程状态和图谱稳定 ID 保留。
