# Foundation C 路线课程设计

1. 开放已列在目录的 C01–C04、C06–C18。沿用 C05 及所有既有课时 ID，为新课引用仓库已有的 1600×900 插图。
2. 四个单元分别实现概率与上下文、提示词与验证、检索与工具、责任与安全。实验统一使用本地数据，通过各自的纯函数计算，复用现有播放器。
3. 每课提供分层讲解、自由实验、挑战、三道诊断题、迁移题及权威参考。C18 运行图书馆咨询助手并导出可审查的案例评估表。
4. 单元测试检查行为和边界，以 1440、390、360px 实测课程及进度，保留原课程与 AI 流程回归。提交独立 PR。

新互动按教学模拟展示，无网络模型和实际工具写入。C16 使用抽象权限操作，训练识别来源并约束执行；C12、C18 在虚构图书馆公开数据中运行。质量为 draft，待真实试学。本轮指 Foundation C 路线，后续阶段按原目录保留。
