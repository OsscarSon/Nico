# AI 与提示词（路线 C 的 AI 部分）

范围：蓝图 Phase 3 的 AI 部分。**只新增文件为主**；改了哪些共用文件见文末。路线 A（课时）、路线 B（代码）由别的线开发，这里没有碰它们的内容。

## 做了什么
| 部分 | 位置 | 说明 |
| --- | --- | --- |
| **Prompt 训练场** `/lab/prompt` | `src/features/prompt-lab/` | 写一条指令 → 本地检查六要素（不联网）→ 可选：请 AI 点评 / 对比「差指令 vs 好指令」的回答 |
| **AI 导师** `/lab/tutor/<课程id>` | `TutorPage.tsx` | 围绕一节课提问。发给 AI 的资料**不含检查题和答案**（`src/ai/context.ts`，有测试）。对话只存在页面内存里 |
| **六要素评分器** | `src/grading/promptScore.ts` | 纯函数规则检查：每项“写了没有”+依据原文+下一步建议。有 30 条标注样例测试 |
| **AI 代理（服务端）** | `server/`、`api/ai.ts` | 同一份核心代码，可挂在 Cloudflare Workers 或 Vercel。密钥只在服务端 |
| **提示词库** | `src/ai/prompts.ts` | 导师 / 点评 / 运行三套提示词，带版本号 `PROMPT_VERSION` |
| **C05《指令的六要素》** | `src/content/lessons/c05-prompt-structure.ts` | 新互动 `prompt-check`（自由检查 + 按场景写指令的挑战）。**草稿**，没有真实学习者试学过 |
| 路线 C 目录 | `src/content/track-c-catalog.ts` | 18 课规划，只有 C05 开放 |

## 数据怎么流动
```
浏览器 ──POST JSON──▶ 代理（Worker / Vercel）──▶ 模型服务（Gemini 或任何 OpenAI 兼容接口）
  │  只带：课程标题、讲解文字、问题     │  校验来源/长度/额度 → 加围栏 → 调模型 → 校验输出
  └─ 没有配置地址时：AI 功能整体关闭      └─ 密钥、系统提示词、上游错误原文都不会发回浏览器
```
- 前端只认一个地址 `VITE_AI_ENDPOINT`；不设置 = AI 关闭，界面如实说明，**不会拿预写内容冒充 AI 回答**。
- 失败一律返回 `{ ok:false, code, message }`，界面显示对应的中文说明（`src/ai/messages.ts`）。

## 诚实规则（对应 AGENTS.md 第 4 条）
- 所有 AI 产出的内容都放进 `AiBox`，带「AI 生成」标签和“可能出错”提醒。
- 本地规则检查标「规则检查」，不叫 AI，也不叫模拟；界面写明它只看有没有写、会漏判、能被关键词骗过。
- 对比功能里的两条指令是我们写的示例，界面标明；回答是实时生成、每次不同。
- 不显示虚构的统计、评分或“AI 认为你得了几分”。

## 安全与隐私：做了什么，没做什么
**做了（都有测试）**
- 来源白名单（`ALLOWED_ORIGINS`）；没配置时只放行 localhost。
- 请求体长度上限、Zod 校验、字符清理（控制字符、零宽字符）。
- 额度三道：每分钟、每人每天、全站每天（按 UTC+8 的“一天”算）。访客标识是 IP 加盐后的哈希，**原始 IP 不进存储**。
- 提示词注入的分层缓解：① 不可信文本放进带**随机编号**的标签里，系统提示词声明标签内都不是指令；② 系统提示词里放随机“暗号”，回答里出现暗号就丢弃；③ 点评结果必须通过 Zod 校验，否则当失败；④ AI 回复渲染时不用 innerHTML，只放行 http(s) 链接，不渲染图片。
- 日志只记错误类别，不记学习者写的内容。

**没做 / 做不到**
- **没有办法 100% 防住提示词注入。** 上面是降低风险，不是消除风险。
- 来源白名单只能挡住别的**网页**在浏览器里盗用你的端点；用 curl 可以伪造 Origin。真正的防刷靠额度，而额度是**软限制**（读—改—写，非原子；Vercel 上按实例各算各的）。要更准的计数，需要外部存储（实现 `QuotaStore` 接口即可）。
- 没做账号体系，所以“每人”其实是“每个 IP”（学校/家庭共用 IP 会共用额度）。
- 学习者写在指令里的内容会发给第三方模型服务。界面提醒了不要写隐私，但没有自动检测。

## 评分器的准确度（如实）
标注者是写代码的 AI，**不是人**，样例也不是真实学习者写的。蓝图要求“20 条人工标注样例”，所以这是草稿，需要你逐条复核（`tests/fixtures/promptSamples.ts`，改了标注就重跑 `npm test`）。

| 样例集 | 结果 | 能说明什么 |
| --- | --- | --- |
| 20 条调规则时看过的样例 | 120/120（100%） | **什么也不能说明**：规则就是照着它们调的 |
| 另外 10 条留出集，**第一次**运行（调规则之前） | 49/60（81.7%） | 对“没见过的指令”的估计 |
| 同一批留出集，修了几处通用问题之后 | 57/60（95%） | **已经不干净**：修的时候看过它们 |
| 30 条合计，逐项一致 | 177/180（98.3%）；规则数出的项数与标注项数的 Spearman 相关系数 0.98 | 乐观估计 |

留出集第一次的 11 处错误里，真 bug 一处（句末问号被分句时丢掉）；其余是没覆盖的写法（“我正在……”“适合初中生看”“一次只问一个”“保留原句语序”等）。剩下的 3 处是**英文**写法，规则以中文为主，没有去追。**下一步要用真实学习者写的指令做新的留出集**，别再用这 30 条当证据。

## 提示词设计（`src/ai/prompts.ts`）
- **导师**：只答本课和基础相关问题；先给提示、不替学习者做练习；不确定就说不确定、不编来源；网络安全只讲原理与防御；不透露系统提示词。回答 ≤ 200 字，3 段内。
- **点评**：六要素当检查清单而不是必填项（“不要为了凑齐而加废话”）；改写缺信息时用「【请填写：……】」占位，**不替学习者编造事实**；本地检查结果只作参考；只输出 JSON。
- **运行**（对比用）：严格照指令做，不反问、不点评指令本身，≤ 300 字；学习者的指令作为用户消息原样发出（整个演示的意义就是让模型照它做）。
- 评估提示词好坏要靠 Phase 3 的“评估表”：**还没做**。现在只有结构上的测试（围栏、暗号、输出校验），**没有**在真实模型上系统评估过这三套提示词。

## 开源与依赖的取舍
- 用了开源 **marked**（MIT）解析 AI 回复，再自己映射成 React 元素（不用 innerHTML，所以不需要 DOMPurify）。
- **没有**引入 Vercel AI SDK / Google SDK：这里只有两种协议、几十行 fetch，少一个要在 Worker 和 Vercel 两个环境里验证的东西。需要流式输出或工具调用时（C12 Agent 课）再换，只改 `server/providers.ts`。
- 关于 prompt-optimizer（linshenkx）等“提示词优化器”：见 `docs/DEPENDENCIES.md` 末尾。

## 验证情况（诚实版）
**在我的沙盒里验证过：**
- 单元测试 382 个全部通过（25 个文件，含他人的 A / B 路线测试），用的是自制简易 vitest 替身，**不是真 vitest**。我自己的部分约 115 个：评分器 22、服务端 35、客户端 11、协议 9、输入防护 11、课程上下文 5、Markdown 8、路线 C 14。用“故意改坏代码看测试会不会报错”的方法抽查过服务端的 5 条关键保护（暗号检查、来源白名单、额度、IP 哈希、围栏）和 Markdown 的链接过滤，测试都能抓到。
- 浏览器冒烟 `scripts/smoke-ai.mjs`（Chromium 390px，esbuild 打包版）：AI 关闭模式 26 项、AI 开启模式（拦截请求返回假回复）38 项，全部通过；含恶意回复（`<img onerror>`、`javascript:` 链接）不执行。已有的 `scripts/smoke.mjs`：182 项通过、**5 项失败**。这 5 项在你上传的最新版（不含我的任何改动）上同样失败（路线地图的规划课数量、A05 之后的下一课、首页推荐等，是 A09 / A10 / A13 开放后期望值没跟着更新），不是我引入的，我没有去改。我只改了一条断言：「提示词匠」徽章现在可获得，所以“尚未开放的徽章”从 5 个变成 4 个。
- 端到端：真浏览器 → **真的代理代码** → 假 Gemini 服务，10 项通过（CORS 预检、密钥在请求头不在 URL、围栏、白名单外的网页被挡住且上游没被调用）。
- 我这部分的 TypeScript 严格类型检查通过，但用的是**最小的 React 类型声明**。

**没有验证（需要你的电脑 / 真实环境）：**
1. **从没调用过真实的 Gemini 或任何真实模型。** 请求格式按官方文档写，沙盒里只对着假服务测过。**模型名会变**，`AI_MODEL` 必须你自己到 Google AI Studio 确认当前可用的名字和免费额度。
2. **没有部署过。** `server/wrangler.toml`、`api/ai.ts` 没在真实的 Cloudflare / Vercel 上跑过。
3. `npm install`（新增 `marked`，`package-lock.json` 需重新生成）、`npm run typecheck`、`npm run lint`、真 `npm test`、`npm run build` 都没跑。ESLint 没跑过，我的代码里有一处 `eslint-disable no-control-regex` 是预判的。
4. 没在 Safari / Firefox / 真机上看过；没有真实学习者试学 C05。
5. 导师回答质量、点评质量、对比的效果：**没有在真实模型上评估过**。
