# D05–D16 课程设计

1. 在 PR #15 上续接现有 D04。D05–D08 用碰撞边界、逐步重力、状态转换和可静音反馈把角色变成可玩系统。
2. D09–D15 用可运行的浏览器教学模型验证场景保存、组件、C# 条件子集、2D 刚体、界面锚点、资源引用和发布检查。
3. D16 综合格子移动、空中状态、收集、出口判分和结果复盘，产出可下载的通关记录。
4. 所有新课有草稿标记和独立居中课头；复用播放器、React、TypeScript 和浏览器原生能力。Phaser 和 Unity 留作对照资料，本批无需增加依赖。
5. 在 1440、390、360px 验证十二门课，保留 D01–D04 流程、原有进度格式与其他路线。

## 从课堂模型到真实引擎

| 课堂规则 | Unity 术语 | 课内验证 |
| --- | --- | --- |
| 每帧读取输入，再更新与显示 | 输入事件、Update、渲染 | 暂停、继续和状态约束 |
| 场地、位置、对象部件 | Scene、Transform、GameObject、Component | 编辑值、播放值和保存值 |
| 重力、地面接触、签到区域 | Rigidbody2D、Collider2D、Is Trigger | 四步积分，分别检查承重与通知 |
| 条件脚本 | C#、bool、&& | 22 组输入的教学解释器验证 |
| 显示当前电量 | Canvas、RectTransform、锚点 | 两种父矩形尺寸和扣电后的值 |
| 图集、声音和发布包 | Sprite Editor、PPU、Build Profiles | 资源许可、入口和子路径查找 |
| 机器人送电池 | 输入驱动对象，电池和出口触发事件 | 空中、落地、收集、失败及通关复盘 |

预览与判分均在浏览器中运行。场景、脚本与发布模型只实现课程所需的行为。D16 导出的 JSON 记录场地版本、操作和结果，可由同一模型重放。
