- **A02 十六进制与文字编码**（9 分钟，新）：十六进制是二进制的短写法（1 位对应 4 位）；十六进制换十进制；#RRGGBB 颜色；ASCII（A=65、a=97）与 Unicode 的区别（简化处有 callout）；复用位开关做挑战（拨出 10、65、97）；3 道选择题；迁移题（#00FF80 的蓝色分量 0x80 = 128）。课头插图已接入（`lesson-a02-hex-encoding.png`，GPT 出图）。没有新增互动组件，也没有改 schema。同时把迁移题"无效输入"的提示从"请输入一个整数，例如 128。"改成"请输入一个整数，只写数字。"——原提示里的示例数字正好是 A02 迁移题的答案，会泄露答案。
- **A03 逻辑门**（9 分钟，新）：AND / OR / NOT / XOR 讲解；逻辑门互动（拨输入、看符号和真值表，当前行标出）；**神秘门挑战**（NOT、OR、XOR）：必须把所有输入都试一遍才能猜，猜错时指出一条自己观察到的、和猜测矛盾的行；3 道选择题；迁移题（两输入逻辑门共有 2^4 = 16 种）。课头插图已用 GPT 重出并接入（四种门的传统形状）。
- **A04 用门搭一个加法器**（10 分钟，新）：二进制加法四种情况与进位；"和 = XOR、进位 = AND"的半加器；半加器自由练习；**搭电路挑战**：自己给「和」和「进位」各选一个门（AND / OR / XOR），点"测试电路"用 4 种输入检查，指出第一个不对的输入以及是哪一位错了（9 种组合里只有 XOR + AND 正确）；3 道选择题；迁移题（两个 8 位数相加最多需要 9 位）。学完 A03 + A04 会获得真实的「守门人」徽章。课头插图已用 GPT 出图并接入（半加器，画的是 1 + 1 = 10）。
- **A05 CPU：取指、译码、执行**（10 分钟，新）：内存是一排编号的格子，CPU 反复做取指 → 译码 → 执行；认识 PC、IR、ACC 三个寄存器。**迷你 CPU 模拟器**（4 条指令 LOAD / ADD / STORE / HALT，10 格内存，思路参考教学模型 Little Man Computer，代码自己写）：每点一次只走一个阶段，说明栏写出当前阶段做了什么，被读 / 被写 / PC 所在的格子有文字标记；ADD 按 8 位溢出（和 A01 呼应）。**预测挑战**：3 个小程序先预测第 8 格的结果，第 3 个有"STORE 覆盖了后面要用的数据"的陷阱；答案由模型实际运行得出，不手写；答对后列出每条指令的变化。3 道选择题；迁移题（4 条指令 × 3 阶段 = 12 步，与模拟器的真实步数一致，有测试保证）。暂无课头插图。
