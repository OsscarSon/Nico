# 可复算结果

## 三类别 Iris 留出测试

UCI Iris，种子 17，训练、验证、测试 90/30/30，使用花瓣长度、宽度。标准化根据训练样本，Softmax 250 轮。三类各 10 条测试记录。损失由 1.098612 降至 .324454。测试项目采用冻结的同一配置。

| 实际与预测 | setosa | versicolor | virginica |
| --- | ---: | ---: | ---: |
| setosa | 10 | 0 | 0 |
| versicolor | 0 | 9 | 1 |
| virginica | 0 | 1 | 9 |

Accuracy、Macro F1、Micro F1 与 Weighted F1 均为 0.933333。Python scikit-learn 从逐行预测重新计算，对混淆矩阵与全部四个指标逐一核对。数值只描述这组留出集。单元测试另有类别支持数不均衡的例子，三个 F1 的定义可分别验证。

## 计算核查

| 对象 | 参照与结果 |
| --- | --- |
| Softmax、两层 tanh 网络 | 独立标量目标函数的中心差分逐项对照参数梯度 |
| LU、QR、积分、热方程、Newton | 重构矩阵与正交性、闭式积分、守恒及导数残差 |
| 统计 | 合理区间、解析 Beta 和 Markov 解、Kaplan–Meier、BH / Bonferroni 的独立小算例 |
| 编译器、调度、流处理、AI | AST 与字节码比较、给定调度序列、乱序和去重输出、手算卷积、掩码的因果边界及策略收敛 |
| 7 道 P3 扩展编程题 | CPython 中两种实现共 56 个用例 |
| P4 进阶编程题 | 8 项分别执行手写、库对照及种子变式，合计 192 个通过用例 |

扩展例题另以 80 位十进制核对二次小根残差，以精确有理数核对 Simpson、Kaplan–Meier 和两状态马尔可夫链，检查 QR 最小二乘残差正交性、约束优化目标、因果注意力权重、VAE 的解析 KL 值和 Laplace 密度比的数值边界。

## 独立外部运行

| 场景 | 实际结果 |
| --- | --- |
| `python scripts/p4-parquet.py`，DuckDB `1.4.4` | 10,000 条合成事件写入 5 个 Parquet 行组。筛选两个地区后得到 `(1, 2500, 12500)` 和 `(3, 2500, 12495)`，与独立逐行累加一致。输出实际执行计划，本机一次查询约 2.29 ms。 |
| `node scripts/p4-external-systems.mjs` | 3 个本地工作线程，其中一个人为失败后重启。重启前后汇总仍为 78，重复任务被忽略。 |
| `node scripts/p4-external-load.mjs` | 本机 HTTP 服务以并发 6 处理 60 次请求。30 个独立写入、30 个幂等重试。复跑中位数约 2.75 ms、p95 约 25.70 ms。 |
| `python scripts/p4-model-serving.py` | 在六个合成点训练二元模型并冻结 JSON 产物，从临时本机 HTTP 服务推理四个独立留出点。4/4 分类正确，Log Loss 为 0.016796，两个无效参数请求均被拒绝。 |

延迟受设备、并发进程和缓存影响。脚本可重复核验任务结果，耗时只记录这次本机运行。
