基线是合并 PR #24 的主分支提交 `0ebc19f`。本分支增加 248 个使用稳定 ID 的草稿课时，将 77 个知识点接到已有互动课。Word 蓝图的 27 门核心课程均有对应课时，30 门课程矩阵保留三个 P5 专项及各项目的实际核验范围。[蓝图对照](COVERAGE.md)

## P0–P3 修复

- 模型比较验证表头、单元格类型、值和行顺序组成的内容指纹，再比对分割、特征、目标、预处理和决策配置。FNV-1a 64 位和序列化字节长度用来检测意外内容变化，用途是本机实验版本标识。
- 训练与对比 Worker 的开发模式计算验证指标，响应不含测试预测、测试点坐标或测试行 ID。Final Evaluation 以冻结的训练配置重新确定性拟合并评估留出集。同一工作台会话针对同一份内容只解锁一次。该流程面向教学，刷新或自行查看原始数据后应把重复测试结果作为探索证据。
- 增加多类别 Softmax 与投票 KNN。三种 F1 按类别支持数、微平均计数和宏平均分别计算。混淆矩阵行表示实际、列表示预测。二元阈值、ROC 和旧实验保留。
- Logistic 和两层神经网络的损失改用 logit 空间，避免截断概率与梯度不一致。对 Softmax 和 tanh 网络独立做逐参数有限差分，核对轻微扰动、极端 logits 和实际训练下降。
- 新增清洗填补、窗口 SQL、PCA 投影、K-means 分配、决策树 Gini、稳定二元损失、反向传播七项真编程判题。原题及其 ID、答题记录保留。
- 新课复用原教学块、KaTeX、独立迁移核验、编程题库、图谱、自评、笔记、收藏、搜索、AI Tutor 与统一备份。新增的研究记录和项目证据使用原报告格式。

## 工作台与项目

七个工作台接入 76 个可运行的教学模型，另有 Web Crypto 原生实验。数值和统计工作台运行矩阵分解、插值、积分、ODE/PDE 入门、优化、频谱、熵、抽样、贝叶斯、功效、因果标准化等计算。Algorithm Arena 接入词法、解析、AST、常量折叠及栈字节码的双执行器核验。Systems Lab 提供真实状态计算的调度、同步、页表、租约、时钟及多数派教学模拟。Data Studio 读取可编辑的 CSV 批次及乱序事件，提供质量统计、拒收、聚合、血缘和水位线，以及 SQLite 的既有真实查询与索引计划对比。

ML Playground 使用小型合成数据实际计算 XOR 训练与反向传播、卷积层、递归门、注意力、单头解码层、向量排序、量化、秩一权重更新、VAE 单次目标、扩散前向过程和强化学习。Research Hub 提供书目登记、复现实验步骤、结果和限制登记及 Markdown 存档，支持原资料库与备份。使用浏览器 Web Crypto 验证临时密钥签名及认证加密，均用固定虚构文本。
