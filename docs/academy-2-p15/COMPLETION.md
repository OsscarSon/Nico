## 教学及技术边界

- 程序题在本机 Python Worker 用多个独立输入核验函数返回值，定位为自主练习。具有专业平台和科研尺度的证明、文字解释、随机化设计和报告仍需本人或教师复核。
- 数学线性代数图侧重二维，消元支持小增广矩阵。统计数字来自教学模型、公示数据或使用者输入。小计数时暂停两比例近似，无法由同一次观察识别因果。
- 学习资料在浏览器中保存。跨设备用验证过的 JSON 文件合并。配置与专业路线可选择以传入文件为准，时间戳较新的同条笔记或报告取优先，保留旧进度合并规则。
- Python 对照包括标准库实现，原课件所引 NumPy/SciPy 等完整示例可在对应环境运行。网络不可用时，教学文字、判分数学题、本机关联和实验仍可用。
- AI 配置模式通过本地响应替身验证协议，正式模型输出依赖部署配置。所有教学仍为草稿，等待真实学习者试学。
