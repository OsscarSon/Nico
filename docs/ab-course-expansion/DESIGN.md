1. 从 `main` 的 `7a413f2` 接续已上线的 B-I01，开放 A21、A22 与中阶 A 六门和 B 余下七门，保留课时 ID、已学记录与先修建议。
2. 两门基础课从 HTTP 响应到请求日志。中阶 A 通过周期写回、服务诊断、协议推演、路由与规则、权限和部署实验，训练读证据与验证修复。
3. 中阶 B 通过竞态状态、API、组件、关系查询、数据结构、构建流程和应用发布，训练从用户动作到应用结果的全链路验证。

## 操作与判分

| 课时 | 操作 | 通过条件 |
| --- | --- | --- |
| A21 HTTP 状态码 | 修复书签，选择响应后的恢复策略 | 错路径停止重复，正确路径依 Retry-After 从 429 恢复到 200 |
| A22 日志 | 按请求关联、排序和选取证据 | r92 的跨服务事件正确且只含该请求，定位早期超时，求出时长 |
| A-I01 数字逻辑 | 译码、选择写回寄存器与写使能 | 两向量低位、进位及未写寄存器符合 ISA 约定 |
| A-I02 Linux | 查状态、按身份修复权限、重测 | 索引活跃且能读取，访客仍被拒绝 |
| A-I03 协议 | 选择地址族、邻居解析、发送预算和 TLS 时机 | IPv6 解析匹配，首批 600 B，并在 TLS 后收到 HTTP 响应 |
| A-I04 网络工程 | 选择前缀、访问策略和地址转换范围 | 办公命中内部最长路由，访客被拒，对外按默认出口转换 |
| A-I05 防御安全 | 选择会话遏制、身份授权和证据保留 | 旧会话 401，新编辑 200，读者 403，保留事件摘要 |
| A-I06 虚拟化与云 | 放置副本，设置就绪条件和存储 | 故障时只向就绪实例转发，两次查询均返回原目录 |
| B-I01 Python | 继续沿用原 Python 实验 | 原身份、内容、插图和浏览器解释器保持兼容 |
| B-I02 JS 与 TS | 调整更新策略、运行时校验与错误状态 | 新请求保留、畸形数据被拒、网络错误可重试 |
| B-I03 后端 | 字段校验、服务端授权和持久操作 | 403/400 不留下记录，成功创建并返回 201 和 Location |
| B-I04 前端 | 选择状态所有者、表单校验和通知方式 | 空提交被拒、有效记录可读、路由往返数据保留 |
| B-I05 关系数据库 | 选择连接、滤项与提交方式 | 正确获得关联行及统计，导入遇外键错误整批回滚 |
| B-I06 数据结构 | 切换 FIFO、LIFO 和按键查找 | 排队公平，撤销最新编辑，重复键返回新记录 |
| B-I07 开发流程 | 选择候选、检查来源和制品 | 拒绝失败版本，发布与通过检查的 SHA 一致的产物 |
| B-I08 全栈项目 | 连通前端路径、角色、去重、持久化 | 页面可访问，编辑成功，重试无重复，读者被拒，重启后数据还在，可导出结果 |

实验在本地运行，使用现有 React 组件与纯函数。SQL、Linux、网络、云和发布环境为针对各课目标的教学模型。真实试学后再调整课程质量状态。
