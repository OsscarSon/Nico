# P5 学术核验与边界

本轮逐项对照 Word 第四至六章的跨领域条目。50 个节点分别落在基础 14、中阶 16、进阶 20 个原 ID 上，新增课时保持草稿。矩阵登记此分支可进入的 604 个知识点，包括原 77 个旧互动课映射。[30 门课程覆盖](COVERAGE.md)

| 核验对象 | 证据 | 尚待验证 |
| --- | --- | --- |
| P5 理论、公式与例题 | 50 个课时通过 Schema 和稳定 ID 对照，公式由 KaTeX 渲染。独立算例核对固定步长、碰撞边界、ADC、去重、窗口方向、PID、RTOS、SLAM、GIS、编辑距离和量子概率。 | 逐页学科独立评阅、全部例题及答案的双人核对与真实学员试学。 |
| 数学推导 | 针对坐标变换、BFS、闭环稳定性、Kalman 增益、位姿图正规方程和量子概率补充推导。独立检查残差梯度为零、两态概率和、量纲与期望。 | 每个复杂知识点仍需独立核对证明前提、边界及教学深度。 |
| 练习和判分 | 新增 16 套可执行 Python 练习。四个固定输入和四个种子输入分别运行手写及库版本，共核验 256 项。23 个知识点接入矩阵、分步、匹配或排序任务。数值实验可执行盲预测和受控对比。 | 尚未逐个为 P4 的 248 个课时新增专属结构化题。P0–P3 保留原题库并重跑参考实现，这些旧课仍需继续扩充题型和讲解。 |
| 既有代码参考 | CPython 独立执行 P2 29 套算法题、P3 12 套数据题、P4 7 套 P3 补充题、P4–P5 24 套题。两种实现加固定/种子案例共 794 项，无跳过。 | 核对只覆盖可运行参考、固定样本和选定种子。其余证明、开放题和真实应用案例仍需人工审核。 |
| 小模型训练 | 对五类模型运行反向传播，并在独立种子的小型合成样本上计损失。独立有限差分对照卷积梯度，检查后续 token 不改变较早输出、LoRA 底座不更新和秩一不变量。RL 对照值迭代与解析的无滑移路径。 | 模型分别是 1D 卷积、单头因果注意力、高斯 VAE、标量时间级扩散与 2×2 LoRA。真实数据外推、完整模型架构和规模化训练未验收。 |
| 七个 P4 项目 | `verify.py` 执行实际数值库、解释器、进程故障重试、SQLite 管道、HTTP 推理、持久服务恢复及论文算法对照。各项目有任务、源码、核验和 100 分量规。 | 生产级多主机容灾、集群数据管道及远端模型部署仍需对应外部环境。 |
| P5 平台和工具链 | C++17 队列已编译并运行。浏览器中的 Arduino、游戏物理、离线遥测与 RTOS 明确标为教学模拟。 | Unity 编辑器、.NET C#、真实 Arduino 板卡、MQTT broker、移动原生工具链及 GPU Shader 编译需外部验收。 |
