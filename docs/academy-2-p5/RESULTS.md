# P5 实际计算与项目记录

## 小模型训练

五类梯度实验使用训练种子 13、不同留出种子、28 个训练样本和 24 个独立样本。批量更新 120 轮，学习率 0.06。保留初始和冻结参数在同一留出集上的结果。各实验损失函数不同，数值适合在同一模型内比较。

| 模型 | 初始 → 最终训练损失 | 留出集基线 → 训练后损失 |
| --- | ---: | ---: |
| 1D 卷积 | 0.197874 → 0.012937 | 0.173486 → 0.018633 |
| 单头因果自注意力 | 0.144556 → 0.024497 | 0.142792 → 0.020449 |
| 高斯 VAE | 2.051967 → 1.312258 | 2.078506 → 1.204233 |
| 四级扩散噪声预测 | 1.077128 → 0.164333 | 1.382109 → 0.300576 |
| 2×2 低秩适配 | 0.623055 → 0.00001166 | 0.414445 → 0.00001170 |

滑移走廊有 6 个状态、15% 反向滑移、240 个实际训练回合。以另一种子跑 60 个贪心回合，60 个抵达，样本平均折扣回报 0.381031。对同一转移模型做值迭代的最优期望为 0.377367。有限样本均值可落在该期望两侧。
