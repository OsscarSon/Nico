### A06 内存与存储

- 核心概念：RAM 工作副本、持久存储、CPU 缓存、命中/未命中、容量与速度取舍。
- 模型：单文档，持久副本、RAM 副本、缓存项；可打开、修改、保存、读取、断电重启。写 RAM 使缓存失效，读未命中时填入缓存，断电清空易失层。
- 自由实验对照：不保存重启丢失修改；保存后重启恢复修改；连续读取产生命中。
- 挑战：保存修改稿、重启并重新打开、观察缓存命中。判定实际内容与重启状态，不能靠点“检查”完成。
- 迁移：8 GiB 总量、旧任务占 5 GiB、新任务需 4 GiB，计算缺少容量。
- 边界：不模拟缓存替换、多层缓存、时序/吞吐性能；立即保存成功是假设，正文明确真实系统有写缓冲、同步与断电保护。
- 原正式素材：`public/art/lesson-a06-memory-layers.png`，只引用，不改图。

### A07 操作系统

- 核心概念：程序/进程、就绪/运行/等待、I/O、单核调度、文件与写权限。
- 模型：浏览器/编辑器两个进程；调度、推进 CPU、请求 I/O、回应、结束；可写笔记与只读系统配置。
- 挑战：浏览器等待 I/O 时，让编辑器获得 CPU 并工作、保存笔记，观察只读配置写入拒绝且内容保持。
- 不允许等待进程直接被调度；I/O 回应只回就绪；单核同时最多运行一个进程。
- 迁移：两个进程交替使用 1ms 时间片，共 8ms，计算其中一个的 CPU 时间。
- 边界：不模拟线程、优先级、真实调度策略、抢占时间或多核性能；每次 tick 是一单位工作。
- 无正式插画：课头留“课程插画待提供”。

### A08 命令行基础

- 核心概念：终端/Shell、命令与参数、当前位置、相对/绝对路径、`.`、`..`、复制与读取、错误诊断。
- 模型：浏览器内纯状态虚拟文件系统，支持 help、pwd、ls、cd、mkdir、touch、cat、cp，支持成对引号路径。
- 挑战：建立 practice，复制 README.txt 为 note.txt，进入目录并实际 cat 阅读。允许等价绝对或相对路径解法，依据最终文件内容、当前位置与阅读记录评分。
- 迁移：从 `/home/nico/projects/demo` 用 cd .. 回到 `/home/nico`，计算级数。
- 边界：不执行真实系统命令，不使用 eval、子进程、宿主文件或网络；拒绝组合命令/重定向/变量等未支持语法，仅能在虚拟 `/home/nico` 内创建内容；不覆盖已有目标；限制命令长度与文件数量。正文区分真实 cp 的覆盖行为。
- 无正式插画：课头留空位，不添加廉价图标。
