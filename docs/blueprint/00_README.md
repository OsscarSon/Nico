# BitLab 比特实验室 — 项目蓝图包

> 工作名称：**BitLab 比特实验室**（可改）。一个"边学边做"的电脑科技工程学习平台。
> 使用者：作者本人 + 朋友（私人使用阶段，暂不公开）。

## 这个包里有什么

| 文件 | 给谁看 | 内容 |
| --- | --- | --- |
| `01_PRODUCT_VISION.md` | 所有人 | 愿景、用户、目标、五条学习路线、原则、不做什么 |
| `02_PHASES.md` | 开发者 / AI 编程助手 | 完整分阶段计划，每阶段交付物与验收标准 |
| `03_CURRICULUM_PLAN.md` | 课程作者 / AI | 每条路线的单元与课时清单、课时模板、质量量规 |
| `04_TECH_ARCHITECTURE.md` | 开发者 / AI 编程助手 | 技术栈、目录结构、内容格式、开源工具、AI 导师、工作规则 |
| `05_UI_UX_SPEC.md` | 设计 / 前端 | 视觉方向、设计令牌、版面、组件、页面线框、动效、无障碍 |
| `06_ART_PROMPTS_FOR_GPT_IMAGE.md` | **美术（GPT 图像模型）** | 统一风格说明 + 每张图的提示词、尺寸、文件名 |

## 给 GPT 图像模型（美术）的快速指引
1. 先完整读 `05_UI_UX_SPEC.md` 的「视觉方向」和「设计令牌」两节。
2. 然后只按 `06_ART_PROMPTS_FOR_GPT_IMAGE.md` 出图。每个资产有独立提示词，先贴「全局风格块」再贴单张提示词。
3. **图里不要出现中文或任何文字**（图像模型写中文容易出错，文字由前端渲染）。
4. 按文件名保存，方便直接放进 `public/art/`。

## 给 AI 编程助手的快速指引
先读 `04_TECH_ARCHITECTURE.md` 末尾的「工作规则」，再从 `02_PHASES.md` 的当前阶段开始，不要一次做多个阶段。
