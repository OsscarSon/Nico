# 02 分阶段计划

原则：**一次只做一个阶段**；每个阶段结束必须满足「验收标准」，并由真实操作验证（不是只写文档）。
预估以"一个人 + AI 助手、业余时间"计，仅作排序参考。

---
## Phase 0 — 决策与地基（约 1 周）
**目标**：定好规则，再动手。
- 确认名称、五条路线、PWA 方案（见 01）。
- 建仓库：React + Vite + TypeScript + pnpm；ESLint、Prettier、Vitest、Playwright。
- 设计令牌（颜色/字体/间距）落成 CSS 变量（见 05）。
- **课时数据格式**（见 04）：用 Zod 校验，内容与组件分离。
- CI：typecheck、lint、test、build 全绿才算通过。
**验收**：空壳应用能在手机和电脑打开，5 个底部/侧边导航可切换；CI 绿；设计令牌文档与代码一致。

## Phase 1 — 学习外壳 + 一节"金标准"课（约 2 周）
**目标**：做出课时播放器模板，并用一节课证明质量。
- 课时播放器：讲解卡片 → 互动 → 检查题 → "试一试" → 小结 → 下一课。
- 左侧/抽屉式章节目录（W3Schools 式），上一课/下一课。
- 本机进度（IndexedDB）：完成、最近学习、连续天数。
- **金标准课：A01「二进制：电脑只认 0 和 1」**，含位开关互动、进制转换挑战。
- 首页：继续学习、今日一课、路线入口（只显示 5 条）。
**验收**：3 位朋友在手机上完整学完这一课，记录卡点；根据反馈改一版；课时模板被冻结为 v1。

## Phase 2 — 路线 A：电脑基础与网络（约 4–6 周）
**目标**：第一条完整路线，约 20 课（清单见 03）。
- 互动组件库：位开关、逻辑门电路画板、CPU 取指执行模拟、IP/子网计算器、DNS 解析动画、TCP 握手时序图、HTTP 请求/响应查看器、数据包路由旅程。
- 每个单元一个小测评 + 单元项目（如"画出访问一个网页的全过程"）。
- 路线结尾作品：**网络诊断面板**（用浏览器可得信息，如 ping 概念、DNS 记录讲解，全部为模拟/教学，不做对真实主机的扫描）。
**验收**：20 课全部通过质量量规（≥ 4/5 每项）；至少 3 位真实学习者试学并留下记录；所有模拟标注"模拟"。

## Phase 3 — 路线 C：AI 与提示词（约 4–6 周）
**目标**：Prompt Optimizer + AI 基础。
- **Prompt 训练场**：写指令 → 对照评分点（角色、任务、上下文、格式、约束、示例）→ 给改写建议 → 对比"差指令 vs 好指令"的输出。
- AI 导师（见 04）：通过服务端代理调用 Gemini 等模型，学习者无需 Key；严格标注 AI 生成；有额度与失败回退。
- 课：大模型是什么、token 与上下文、提示词结构、Few-shot、思维链何时有用、RAG、Agent 基础、幻觉与核查、AI 安全。
- 作品：**一个能解决真实小问题的 AI 助手原型**（含评估表）。
**验收**：Prompt 评分器在 20 条人工标注样例上，与人工评分趋势一致（记录一致率）；AI 失败时诚实回退，不伪造回答。

## Phase 4 — 路线 B：编程与网站（约 4–6 周）
- 浏览器内 Python（Pyodide）与 JS 沙盒，"试一试"编辑器（CodeMirror 或 Monaco）。
- 课：变量、条件、循环、函数、列表与字典、HTML/CSS、DOM、fetch/API、Git 与 GitHub、部署一个静态页。
- 作品：个人网页 + 一个小工具。
**验收**：代码在 Worker 中执行，有超时与停止；不执行服务端任意代码。

## Phase 5 — 路线 E：Google 与效率自动化（约 4 周）
- 浏览器内表格引擎（HyperFormula 或自研子集）教公式；图表；数据清洗。
- 课：Excel/Sheets 公式、查找（XLOOKUP/VLOOKUP）、数据透视思想、Apps Script 入门（先在文档中演示 + 复制到真实 Sheets 的练习）、Gemini API 调用、Colab 入门、Looker Studio 概念。
- 作品：**自动报表**（表格 + 脚本 + AI 总结）。
**验收**：每个公式练习有自动判分；Apps Script 课明确标注"需在你自己的 Google 账号中运行"，平台本身不要求 Google 授权。

## Phase 6 — 路线 D：游戏开发（约 4–6 周）
- 浏览器内 2D 小游戏（Phaser，开源）教游戏循环、输入、碰撞、状态。
- Unity 课：编辑器界面、GameObject/Component、脚本 C#、物理、UI；以截图/短视频 + C# 概念题为主（Unity 编辑器无法在网页里运行，老实标注）。
- 作品：一个小游戏（Phaser 版）+ Unity 版实现说明。
**验收**：游戏概念与 Unity 术语一一对照表完成；Phaser 互动在手机上可操作。

## Phase 7 — 作品集与复习（约 2–3 周）
- 作品页：每个项目的说明、截图、学到的技能；可导出为 PDF/Markdown。
- 间隔复习：错题与概念卡，每日 5 题。
- 徽章（见 06 美术）按真实完成条件发放，不可虚构。

## Phase 8 — 打磨与可选扩展（持续）
- PWA 离线、安装提示、无障碍（键盘、对比度、减少动效）、性能（首屏 < 3 秒 @ 4G）。
- 朋友反馈周期：每两周一次，修最痛的 5 个问题。
- 可选：Supabase 同步进度；Capacitor 打包；更多路线内容；公开发布前的内容与版权审查。

---
## 每阶段通用要求
1. 开发前写 3–5 行计划；结束时更新 `docs/STATUS.md`（完成/未完成/已知问题/下一步）。
2. 运行 typecheck、lint、测试、构建；**如实**报告结果，失败就写失败。
3. 任何"已验证/已发布"都必须有证据（截图、测试、真实学习者记录）。
4. 小提交，小评审；不改无关文件。
