# 05 UI / UX 设计规范

## 视觉方向：工程笔记本 × 电路走线
**场景**：学习者像在工程师的方格笔记本上做实验。页面是冷灰蓝的方格纸，内容是印刷感的"实验器件"，学习路线是一条电路走线，学到哪里，信号（琥珀色）就点亮到哪里。

**记忆点只放一处**：**走线路线图（Path Map）**——课时是焊盘节点，走线以 45° 折角连接；已完成的段落亮琥珀色，当前节点有微弱脉冲，未解锁的段落是灰色虚线。其余界面保持安静克制。

## 设计令牌

### 颜色
| 名称 | 值 | 用途 |
| --- | --- | --- |
| paper 纸面 | `#F2F4F7` | 页面背景 |
| grid 网格线 | `#DCE2EA` | 背景方格、分隔线 |
| panel 面板 | `#FFFFFF` | 卡片、互动器件底色 |
| ink 墨水 | `#14213D` | 正文标题、器件描边 |
| muted 次要 | `#5B6577` | 说明文字（对比度 ≥ 4.5:1） |
| trace 走线蓝 | `#2457F5` | 主色：链接、主按钮、选中 |
| signal 信号琥珀 | `#FFB020` | 进度点亮、当前位置、高亮 |
| pass 通过绿 | `#12A46B` | 答对、完成 |
| fault 故障红 | `#E5484D` | 答错、错误 |

夜间模式（可选，Phase 8）：`paper #0F1A2E`、`panel #16243D`、`ink #E8EEF8`、其余颜色略提亮；方格线 `#223452`。

### 字体
- 标题/界面：**Noto Sans SC**（中文）+ **Bricolage Grotesque**（拉丁字母与数字，用于大标题和英文术语）。
- 代码与二进制：**JetBrains Mono**。
- 字阶（rem）：12 / 14 / 16（正文）/ 18 / 22 / 28 / 36 / 48；正文行高 1.7；行宽 ≤ 68 个字符（约 34 个汉字/行以上不拉太宽）。
- 句式用**句号式短句**；标签使用常规大小写，不用全大写，不加装饰性小标题。

### 形状与层次（不要所有东西同一个圆角）
- 面板：圆角 6px，1px `grid` 边框，无阴影。
- **互动器件（模拟、编辑器、答题块）**：2px `ink` 描边 + 4px 硬偏移阴影（`4px 4px 0 ink`），像印刷的实验器件，一眼看出"这里可以动手"。
- 按钮：圆角 10px；主按钮 `trace` 底白字；次按钮描边。
- 标签/状态：胶囊形（全圆角）。
- 间距基数 4px；常用 8 / 12 / 16 / 24 / 40。

### 动效
- 只在**响应操作**时有动效：位开关翻转、信号沿走线流动（答对后路线点亮）、数据包沿链路移动。
- 一次性页面入场动效最多一处（首页走线点亮）。
- 支持 `prefers-reduced-motion`：关闭所有流动动画，直接显示结果状态。

## 导航与版面
**手机（优先）**：底部 5 项：首页 · 路线 · 实验 · 作品 · 我的。顶部只放当前页标题与返回。
**桌面**：左侧栏同样 5 项；课时页右侧显示本课目录。
**课时页**（核心）：
```
手机                         桌面
┌──────────────────┐        ┌────┬───────────────┬────────┐
│ ←  A01 二进制  ▓▓░│        │导航│  讲解(≤68ch)   │ 本课目录│
├──────────────────┤        │    │                │ ·钩子   │
│ [讲解] [动手] [检查]│        │    ├───────────────┤ ·讲解   │
│                  │        │    │ 互动器件(粘性)  │ ·互动   │
│  内容区           │        │    │                │ ·检查   │
│                  │        └────┴───────────────┴────────┘
│ [上一步]  [下一步]  │
└──────────────────┘
```
手机用顶部三段标签切换"讲解/动手/检查"，保留状态；桌面讲解在左、互动器件在右并粘性固定。

## 页面清单与要点
1. **首页**：「今日一课」大卡（继续上次位置，没有记录则推荐 A01）→ 五条路线的走线缩略图 → 最近作品。没有记录时是邀请，不显示假进度。
2. **路线总览**：5 张路线卡，每张一个符号 + 一句话 + 课数 + 状态（草稿/试学/正式）。
3. **路线地图**：记忆点页面。垂直走线，节点=课时，单元用分隔线命名。点击节点弹出摘要与"开始"。
4. **课时播放器**：如上。顶部进度条按"块"推进；答错不扣分，给"为什么 + 回去看哪段"。
5. **实验台**：所有可独立使用的器件集合（位开关、子网计算器、DNS 动画、Prompt 训练场、公式沙盒）。
6. **Prompt 训练场**：左写指令，右看评分点（逐项勾亮）与改写建议；下方"差 vs 好"并排对比输出。AI 输出带"AI 生成"标。
7. **作品**：卡片网格 + 详情（目标、做法、截图、学到的技能、导出）。
8. **我的**：连续天数、已学课数、复习队列、设置（字号、夜间、减少动效）、数据导出/清除。
9. **空/错误/离线**：每个都说明发生了什么与下一步（例："这里还没有作品。完成 A 路线第一单元后，你可以做出第一个。"）。错误不道歉、不含糊。

## 文案规则
- 按钮写具体动作：**开始这一课**、**检查答案**、**保存作品**。同一动作全程同名。
- 用户视角用词：不说"组件挂载失败"，说"这个练习没能加载，刷新后重试。"
- 英文技术词首次出现：`TCP（传输控制协议）`。
- 不用空话（"探索无限可能"）；每个字做一件事。

## 无障碍与质量底线
- 全部可键盘操作，焦点环 2px `trace` + 2px 偏移，始终可见。
- 触控目标 ≥ 44×44px。
- 颜色不是唯一信号：答对/答错同时用图标与文字。
- 互动器件有文字替代说明；动画有静态等价说明。
- 屏幕 360px 宽无横向滚动；4× CPU 降速下首屏可用。
- axe-core 自动检查无严重问题。

## 组件清单（给前端）
`PathMap`、`LessonShell`、`Block.Explain`、`Block.Quiz`、`Block.Transfer`、`Device`（互动器件容器，含描边与硬阴影）、`ProgressTrace`（走线进度条）、`StatusPill`、`Callout`（"这里简化了"提示）、`SimLabel`（"模拟"标签）、`AiLabel`（"AI 生成"标签）、`EmptyState`、`BottomNav` / `SideNav`、`CodeEditor`、`TermTip`（术语悬浮解释）。
