# 03 课程计划与质量标准

## 课时模板（每课必须遵守）
每课 5–12 分钟，一个核心概念。结构固定：

1. **钩子（30 秒）**：一个具体问题或现象。例："你点开网页，0.3 秒内到底发生了什么？"
2. **讲解（2–3 分钟）**：3–5 个短块；每块一个想法；配图或动画；英文术语第一次出现给中文对照。
3. **互动（2–4 分钟）**：必须动手（拖、点、改、填、写），并立刻有反馈。
4. **检查（1–2 分钟）**：2–3 题；**错误选项要对应真实误解**；答错给"为什么错 + 去看哪里"。
5. **迁移题（1 分钟）**：换个场景再用一次，不是重复题。
6. **小结 + 下一步**：3 句话总结；指向下一课；给"想深入"的外部来源（官方文档/权威教材）。

每课元数据：`id`、`title`、`track`、`unit`、`prerequisites[]`、`objectives[]`（可检验的动词：能解释/能计算/能写出）、`estimatedMinutes`、`sources[]`、`simulationLabel`（若含模拟）。

## 质量量规（上线门槛）
六项各 0–5 分，**每项 ≥ 4 且总分 ≥ 25/30** 才能标为"正式"，否则标"草稿/试学"。

| 项目 | 4–5 分的样子 |
| --- | --- |
| 准确性 | 事实与术语正确；引用权威来源；简化处已标明"这里简化了" |
| 教学设计 | 目标可检验；先修明确；由易到难；有误解纠正 |
| 互动质量 | 操作有意义、反馈具体，不是装饰动画 |
| 评测质量 | 题目考理解不是记忆；错误选项有诊断价值；有迁移题 |
| 可读性与体验 | 句子短；手机可读；无大段文字墙；加载快 |
| 真实学习证据 | ≥ 3 位真实学习者试过；完成率与卡点已记录并改进 |

**评分必须附证据**（来源链接、试学记录、截图）。没有证据不打分。

## 路线 A：电脑基础与网络（约 20 课）
**单元 A1 数字世界的语言**
- A01 二进制：电脑只认 0 和 1（金标准课）
- A02 十六进制与颜色、文字编码（ASCII/Unicode）
- A03 逻辑门：AND / OR / NOT / XOR
- A04 用门搭一个加法器

**单元 A2 电脑内部**
- A05 CPU：取指、译码、执行（循环模拟）
- A06 内存与存储：RAM、硬盘、缓存为什么要分层
- A07 操作系统做什么：进程、文件、权限
- A08 命令行第一步（安全的沙盒终端）

**单元 A3 网络如何连接**
- A09 网络是什么：设备、链路、协议的分层想法
- A10 IP 地址与子网（含计算器）
- A11 MAC 地址、交换机、路由器各司何职
- A12 数据包：切开、编号、走不同路再拼起来
- A13 DNS：名字怎么变成地址（解析动画）
- A14 TCP：三次握手、重传、为什么可靠
- A15 UDP 与何时不要可靠（视频通话、游戏）
- A16 HTTP/HTTPS：一次请求与响应、状态码、证书的直觉
- A17 一次网页访问的完整旅程（综合）

**单元 A4 安全意识（防御向）**
- A18 密码、哈希、为什么不能明文保存
- A19 钓鱼与社会工程：如何识别
- A20 最小权限与更新：日常防护清单

**路线 A 作品**：「一次网页访问全过程」交互图 + 网络诊断面板（教学模拟）。

## 路线 C：AI 与提示词（约 18 课）
**单元 C1 理解大模型**：C01 大模型是什么与不是什么；C02 token、上下文窗口；C03 温度与随机；C04 幻觉与核查。
**单元 C2 写好指令（Prompt Optimizer）**：C05 指令的六要素；C06 给例子（Few-shot）；C07 指定格式（JSON/表格/步骤）；C08 拆任务与多步提示；C09 让模型自我检查；C10 提示词调优循环（写→测→改→记录）。
**单元 C3 用 AI 做东西**：C11 RAG：让模型读你的资料；C12 工具调用与 Agent 基础；C13 评估：怎么知道一个提示词变好了；C14 本地小模型与隐私。
**单元 C4 责任与安全**：C15 偏见与版权；C16 提示词注入（防御向）；C17 什么时候不该用 AI；C18 综合项目：AI 助手 + 评估表。

## 路线 B：编程与网站（约 20 课，概要）
Python：变量、类型、条件、循环、函数、列表/字典、读写文件（模拟）、调试。
Web：HTML 结构、CSS 布局、JS 与 DOM、事件、fetch 与 JSON、Git 基础与 GitHub、发布静态站。

## 路线 E：Google 与效率自动化（约 16 课，概要）
公式基础、引用与相对/绝对地址、IF/SUMIF/COUNTIF、XLOOKUP/VLOOKUP/INDEX-MATCH、日期与文本函数、数据清洗、透视思想、图表选择、Apps Script 入门与自动化、Gemini API 入门、Colab 简介、Looker Studio 概念。

## 路线 D：游戏开发（约 16 课，概要）
游戏循环、坐标与向量、输入、碰撞、状态机、音效与反馈；Unity：界面、GameObject/Component、C# 脚本、物理、UI、打包；Phaser/Godot 对照学习。
