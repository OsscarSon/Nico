# 01 产品愿景

## 一句话
**一个让零基础的人，用每天 10–20 分钟，通过"看一点、动手试、做出东西"，学会电脑科技工程的学习平台。**

## 灵感与差异
参考 W3Schools 一类教程站的好处：左侧章节目录、短讲解、代码示例、"自己动手试一试"。
BitLab 在此基础上补三样东西：
1. **可视化模拟**：数据包怎么走、TCP 怎么握手、CPU 怎么取指执行，用动画和拖拽理解，不只读文字。
2. **AI 能力训练**：提示词优化器、与大模型对话的方法，把"怎么给 AI 下指令"当作一门正式技能。
3. **作品导向**：每条路线结尾都有能留下来的小项目。

## 用户
- 主要：作者与朋友（中文为主，英文技术名词并列）。
- 假设：零基础到初级，手机和电脑都会用。
- 公开发布：**以后再说**。现在不做账号系统、支付、社区。

## 平台决策（推荐）
**手机优先的网页应用（PWA）**：一套代码，手机浏览器可"添加到主屏幕"，也能在电脑上用，能离线读已加载课程。
理由：朋友之间发链接即可用，不用上架；以后如需上架商店，再用 Capacitor 打包同一套代码。

## 五条学习路线（由原十个学院合并）
| 代号 | 路线 | 包含 |
| --- | --- | --- |
| A | **电脑基础与网络** | 二进制、逻辑门、CPU/内存、操作系统、IP/DNS/TCP/HTTP、安全意识 |
| B | **编程与网站** | Python、JavaScript、HTML/CSS、Git、API、简单云端部署 |
| C | **AI 与提示词** | Prompt Optimizer、大模型原理、RAG、Agent、本地模型、AI 安全与评估 |
| D | **游戏开发** | 游戏循环、2D 小游戏、Unity 基础与 C#、Godot/Phaser 对照 |
| E | **Google 与效率自动化** | Excel/Google Sheets、公式与图表、Apps Script、Gemini API、Colab、Looker Studio |

路线之间共享课时（例如"变量"在 B 和 D 都用），以课时 ID 引用，不复制内容。

## 最终效果（3 个月后的学习者）
- 能解释一次网页访问背后发生了什么（DNS→TCP→HTTP）。
- 能写简单 Python/JS 程序，会用 Git。
- 能写出结构清晰、可复现的 AI 指令，并判断输出好坏。
- 能用表格公式和脚本自动化日常工作。
- 有 4–5 个作品：网络诊断面板、Sheets 自动报表、AI 助手原型、一个小游戏、一个个人网页。

## 成功指标（真实的，不是自评）
- 朋友试学：每课至少 3 位真实学习者试过，完成率 ≥ 70%，卡点被记录并修复。
- 每课"我学会了吗"自评 + 一道迁移题，正确率可统计。
- 一周内回访率（自己和朋友）作为粘性参考。

## 设计原则
1. **质量优先于数量**：宁可 40 节打磨过的课，不要 400 节空壳。
2. **做中学**：每课至少一个可操作互动，不是纯阅读。
3. **诚实**：模拟就标"模拟"；AI 回答就标"AI 生成"；没有证据不写"已验证"。
4. **小步前进**：一课 5–12 分钟，一课一个核心概念。
5. **中文优先**：解释用中文，保留英文术语并给出对照。
6. **安全边界**：网络和安全内容只教防御与原理；不提供对真实系统的攻击步骤。

## 不做什么（当前）
- 不做账号注册 / 社区 / 排行榜 / 付费。
- 不做原生 App（先 PWA）。
- 不做"十个学院全部铺开"：先把 A 和 C 做到高质量。
- 不让学习者填自己的 API Key。
