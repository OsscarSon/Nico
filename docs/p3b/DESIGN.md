# B 路线结业课程设计

1. B18 用原 HTML/CSS 编辑器和浏览器 DOM 判分完成个人作品页，检查语义结构、有效锚点、项目条目和实际颜色。
2. B19 用原 JavaScript 沙盒制作阅读时长工具，以不同输入、重复点击、空值和非法输入检查实际页面内容。
3. B20 以一次社团积分发布串联本地 API、Git 快照、产物和访问验证。复用现有纯函数并按当前发布结果判分。
4. 为三课各接入一张以 B12 为风格参考生成的新插图。全量检查和三尺寸浏览器操作后提交独立 PR。

三课沿用已规划的课程 ID、四单元目录和讲解结构。质量维持 draft，来源链接选用 MDN、Pro Git 和 GitHub Docs。B18 和 B19 的作品在课内运行，可复制源代码带走。B20 的网站和 API 都在本地模型中，不会修改真实仓库或托管站点。
