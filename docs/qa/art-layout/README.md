复现：`npm run build`，另一终端 `npm run preview -- --port 4184`，再运行 `BASE_URL=http://localhost:4184 SCREENSHOT_DIR=test-results/art-audit node scripts/audit-lesson-art.mjs`。脚本从真实课程注册表枚举available课时，自动包含新增课程，不硬编码本轮29门。

`node scripts/center-lesson-art.mjs` 独立于服务器验证四张居中副本的像素内容与尺寸；`--write`仅用于生成缺失副本，已有目标文件时排他写入会拒绝覆盖。工具只用项目既有Playwright和浏览器Canvas，无新依赖。
