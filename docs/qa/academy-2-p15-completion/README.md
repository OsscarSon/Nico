## 独立学术核验

- 对照从题面重新推得的答案检查 82 页的 328 道主练习和 87 道闭合补充题。开放题按原检查点人工复核。16 个模板的每个参数组合分别验证练习题、迁移题和判分，总计 224 个组合。
- 复算并检查补充例题的主要结果、定义域、方向和假设。例如将分式回代、用齐次方程核对零空间、用真实残差核对回归及单侧双侧尾部。明确了零向量题的输入格式和方向导数例题的方向向量。
- 29 个实验默认输入都用独立结果核对。额外验证非满秩、不相容、复特征值、区间尾概率、随机种子、配对符号秩、拒绝域和区间。矩阵重构、Taylor 误差和统计参考值使用代数推算或 NumPy/SciPy 对照。
- 公式的数学核验覆盖实验涉及的闭合计算与统计条件。KaTeX 内容测试另行检查可读排版和回退。开放证明和涉及真实学习成效的部分仍需人工学术审阅和试学。

## 性能

- Vite 生产主 JavaScript 从上轮约 582.26 kB gzip 增至约 588.00 kB gzip，增量约 5.74 kB。学习资料索引、实验目录、课内代码与 KaTeX 继续由路由或操作按需加载。三个视口验证首页无这些教学专属资源的请求。
- 不额外引入运行时依赖。当前程序比较用本地 Python Worker，首次启动速度受设备及官方资源供给影响。上述结果为包体与按需加载验证，未将测试环境的本机时延作为实际生产指标。

## 复查

运行 `npm run preview` 后执行 `npm run smoke:academy2-completion`。要复跑真运行时检查，可将 `PYODIDE_ASSET_DIR` 指向解压后的官方 `pyodide@314.0.8` npm 包目录。要复跑配置版 AI 适配器检查，可用 `VITE_AI_ENDPOINT=/api/p15-test` 单独构建并预览，再设置 `AI_BASE_URL` 指向该预览地址，浏览器会拦截该测试请求。
