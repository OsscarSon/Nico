## 验收重点

- 30 个入口和所有主归属都经过测试核对，212 个旧编号各出现一次，116 个可学课时的对象和 ID 全部保持一致。
- 在桌面用键盘、在窄屏用触控选阶段。通过旧编号找到 A22，展开网络模块，再进入原课时。Attention 图谱检查五项先修，并跳转到向量点积。
- 专业路线选择刷新后持续生效。以旧 `schemaVersion: 1` 记录进入新版，原续学优先，已有完成成绩与课时 ID 保留。
- 实测函数系数、抽样量、插入排序错误输入和排序过程、位开关及七个实验室的入口。15 个学术链接均核对可访问。
- 所有现有课程文件、原插图、独立判分、进度存储和 AI 代码无改动。P3-A 的静态保护仍检查其余内容。本轮重整的三个首页/档案文件改用实际页面和资料保存回归验证。
