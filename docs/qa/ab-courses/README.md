## 模型边界

新增实验通过确定性的教学运行观察实际结果。虚构服务、日志、协议、关系查询与发布流程都在本地运行。未进行实体手机、Safari 或真实学习者试学；课程显示草稿。B-I01 保留现有真实 Python 解释器及环境加载行为。
