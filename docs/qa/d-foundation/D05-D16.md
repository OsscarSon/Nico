## 本地结果

- `npm run typecheck`、`npm run lint`、`npm test`（48 文件、670 项）、`npm run build` 通过。构建保留体积提示。
- `npm run smoke:d` 共 48 条流程，覆盖 16 课 × 1440、390、360px。逐课验证开场、自由实验、错误状态、挑战、检查题、迁移与刷新进度。
- `npm run smoke`、`npm run smoke:academy`（157 项）、`npm run smoke:p2`（258 项）和 `npm run smoke:ai`（关闭模式）通过。
- 新图为独立 AI 生成 PNG，使用 1600×900 的浅色方格纸版式。D10 使用新文件名，原 Unity 场景图与其他旧图保留。

浏览器验证使用 Chromium 与手机视口模拟。音效检验记录浏览器收到的播放请求与静音状态。C# 实验支持可解释的条件表达式子集。Unity 视图、物理和发布为教学模型，未启动编辑器或公网部署。新课待真实试学，均保留草稿标记。

一次并行验证出现原有 JavaScript 有限循环测试超时，隔离重跑全量套件后 670 项全部通过。循环执行与既有测试断言保持原样。
