# P1 教学质量检查与边界

## 教学组成

- 每页有定义、原理与推导、带步骤例题、常见误区、3 个分层练习及第 4 道独立迁移核验。共 82 页、328 道可判分题。12 个需要额外论证的主题配开放练习和论证检查点。
- 按模块组织可视化、互动与实现。例如用数值旋转检查单位圆与向量范数、以公开实测样本比较组内相关与汇总相关、在异常点与小样本下检查统计量是否仍可解释。图形同时有文本数值。
- 页面运行本地、从零编写的 TypeScript 计算。Python 栏包含可独立执行的专业库示例，用同一模型或默认参数核对。17 段不同示例实际执行。数学包括 NumPy、SymPy、SciPy；统计包括标准库、SciPy 和 scikit-learn。
- 参考资料按模块提供。代数使用 OpenStax，线性代数、微积分、离散数学及概率使用 MIT OpenCourseWare，统计还参考 OpenIntro、Berkeley Data 8 与 MIT 18.650 Statistics for Applications。
- 四个项目必须运行满足任务的设置并提交三项数值证据才能记录通过与导出。项目报告可包含学习者的解释。开放证明与文字分析由学习者对照检查点或教师核对。

| 阶段 | 核验重点 | 当前教学边界 |
| --- | --- | --- |
| P1A | 从定义域到反函数，用反例与逆否分别说明逻辑；曲线根、顶点和函数值由真实系数导出。 | 可视化侧重二维图与基础模型。通用符号证明可通过 SymPy 对照实验，开放论证由人判断。 |
| P1B | 分清总体与样本、分母 n−1、分位算法与围栏；Iris 数据逐条比对 scikit-learn 的校正版本。 | 分位采用线性插值；围栏探索异常，不给自动删除结论。Iris 报告属于对该样本的描述。 |
| P1C | 核对矩阵形状、秩、奇异值、有限差分、梯形积分、负梯度下降与 BFS 路径。 | 矩阵实验为实数 2×2，图为无向无权。SVD 一般定义与证明在正文；数值容差和复杂情形用 NumPy 对照。 |
| P1D | 核对连续与离散模型、抽样分布、合并与未合并标准误、Welch 自由度、卡方、F、秩与回归；A/B 数据不足时抑制近似输出。 | 浏览器模型模块给出 t、χ²、F 和 U 等统计量，尾概率和分布区间用专业库例题复核。A/B 采用教学计数和近似比例区间，未模拟真实生产随机分流。 |

## 图谱与学习记录

- 知识点 ID 由清单持有，改课名、重排或移动时保留 ID 并更新定位。自动测试核对全部目录位置。各边保留学术理由，展示 Required、Recommended、Related。必备与建议关系检查端点、重复、自环和有向环，Required 跨阶段及跨领域另做审计。Related 边用于延伸学习。
- 打开教学页记录学习中。三道实际分层题通过后显示已完成，再答对独立迁移题才显示已掌握。复核答错或核验满 45 天未更新则显示需要复习。章节、模块和课程采用知识点实测证据汇总，课程通过还包括项目。P1 采用一知识点一课时。
- 自评与正式练习是独立字段，并在本机刷新后保留。既有 `nico-progress` v1、旧课时链接与成绩照常读取，知识点与项目数据写入新键。无效或未来版本的知识数据在覆盖前先备份。
- 这次检查使用公开教材、自动测试、实机浏览器和独立库对照。当前 82 页均为草稿，后续收集真人试学与开放题反馈。知识记录保存在当前浏览器，原学习记录导入导出继续使用既有格式。
