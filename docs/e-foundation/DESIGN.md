# Foundation E 设计

1. E01–E05 用受限公式解释器实际计算单元格、复制引用、条件、精确查找与日期文本。
2. E06–E08 用同一批虚构活动记录清洗数据、分组汇总和选择图表。E09–E15 验证批处理、定时器、审批、请求、运行时、看板和去重流水线。
3. E16 将原始数据转为可审查的分组报表，以独立样例验证计算，审核后导出 CSV。
4. 沿用浏览器和 TypeScript。表格课程不需要引入 HyperFormula；Apps Script、Gemini、Colab 和 Looker Studio 使用明确标注的本地模型。
5. 逐课交付独立插图、草稿和互动，在 1440、390、360px 兑现所有学习路径，保留现有素材、进度及中高级规划。
